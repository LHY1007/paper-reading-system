一页概览

研究解决什么问题？

验证不同论文只能替换内容数据，不能改变 CANVAS 页面骨架。

核心数据是什么？

一份符合 JSON Schema 的结构化论文内容清单。

模型输入与输出是什么？

输入论文数据，输出固定 CANVAS 结构的独立 HTML。

主要生物学发现是什么？

该文件不承载生物学结论，只验证组件结构。

主要临床结果是什么？

该文件不承载临床结论，只验证交互和渲染。

最重要的限制是什么？

冒烟测试不能替代真实论文的 PDF 完整性与浏览器回归。

方法流程概括

结构化清单 → 克隆标准 CANVAS 组件 → 外壳锁 → 组件锁 → 浏览器回归。

整体结论

该测试只用于验证渲染器、外壳锁和组件锁，不代表任何真实论文内容。

测试文件不进入正式论文发布。
