# V0.8.2 新版固定壳层生成对照报告

本报告使用本轮上传的原始 PDF，在本地执行当前 GitHub 分支的 PDF→manifest→固定 CANVAS 壳层渲染流程。为隔离产品架构与翻译质量，候选 HTML 使用 identity translation，即中文槽位暂时复制英文；它们是结构与内容抽取诊断件，不是最终交付版。

## 核心结论

固定代码层已经解决旧批量版本的产品退化。新版 CANVAS、Maas 和 Valanarasu 均通过壳层、组件和渲染后架构门禁，并保留 47 个固定全局按钮。旧 Maas 和旧 Valanarasu 不具备标准 CANVAS 组件体系，关键目录、设置、批注、查看器、参考文献弹窗和缩放结构缺失。

内容层尚未达到 0.82 原版 CANVAS。新版 CANVAS 从同一篇 29 页主论文 PDF 重新生成后得到 154 个双语单元、6 个图卡、0 个表卡和 111 条参考文献；0.82 原版 CANVAS 为 111 个双语单元、14 个图卡、5 个表卡和 112 条参考文献。差异不再来自产品壳层被删减，而来自内容源和解析规则。

其中图表差距有明确来源：本轮上传的主论文 PDF 只含图形摘要及主图 1–5，不含原版 HTML 中的补充图 S1–S8 和补充表 S1–S5，因此单凭主 PDF 不可能生成与原版相同的 19 个图表组件。

## 当前判断

新版架构已经证明任何论文都可以复用完全相同的 CANVAS 产品框架，旧批量版本的功能退化问题已被隔离并阻断。当前不能作为最终版的原因已经转移到可变数据层：补充材料源不完整、正文段落切分仍不稳定、表格没有重建为表卡、参考文献不全、元数据和概览抽取质量不足，以及正式中文翻译尚未执行。

本诊断包不代表最终发布。PR 继续保持 draft，不合并。
