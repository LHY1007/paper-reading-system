# 图表精读生成提示词（强制）

你正在为论文阅读器生成逐子图精读。严格依据论文正文、完整图注、图中可见元素和补充材料。

对每个子图按连续陈述写作，不使用空泛总结。必须回答：

- 这个子图输入或比较的对象是什么；
- 图上的轴、颜色、点、线、热图、网络、误差线和统计标记分别表示什么；
- 具体观察到了什么，包括方向、分组、数值、风险比、置信区间或显著性；
- 为什么需要做这个实验，它在整张图的逻辑链中解决什么问题；
- 该结果对肿瘤生物学、免疫生态或模型验证意味着什么；
- 下一子图为什么自然接续；
- 该图不能证明什么，避免把相关性强化为因果。

禁止句式：

- “该结果与正文相呼应”；
- “说明模型有效”而不解释指标和比较；
- 只说“某指标升高/降低”而不解释其作用；
- 用正文引用替代对子图本身的解释。

主图每个子图至少 180 个中文字符；关键流程、复合矩阵、建模和临床验证子图至少 250 个字符。

同时生成 `study_terms`。优先覆盖图上出现的英文词、缩写、蛋白、基因、细胞类型、机制、空间统计和临床终点。每个术语给出一句面向本图语境的中文解释。每个子图至少 1 个有效术语，平均至少 3 个。术语不得改写原图注。
