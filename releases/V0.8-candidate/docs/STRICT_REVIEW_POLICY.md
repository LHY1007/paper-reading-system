# CANVAS V0.8 严格审查政策

## 内容锁
V0.8 不得修改 V0.7.8 的 `quick-pane`、`bilingual-pane`、参考文献数据及图表精读来源脚本。构建器逐项比较 SHA256；任一不一致即阻断交付。

## 图像区域定位
1. 禁止依据面板字母、版式经验或模型视觉判断自动生成子图坐标。
2. 每个坐标必须包含 figure_id、panel_id、x、y、w、h 和 `verified=true`。
3. 坐标必须经过原始高清图人工核对、缩放后核对和跨分辨率浏览器核对。
4. 缺少合格坐标时，系统只能聚焦文字解读，不得在图像上显示定位框。

## 图表入口
- 每个具有精读数据的图仅允许一个精读入口。
- 表格和普通文本章节不得出现精读入口。
- 快速预览、正文引用和右侧图栏必须指向同一个资源 ID。

## 新交互的失效保护
运行时审查失败时，新增搜索和潜在定位功能被禁用，原 V0.7.8 正文、图栏、批注、绘图及图表精读保持可用。
