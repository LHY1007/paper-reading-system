# CANVAS V0.8 候选版修改记录

本版本基于 V0.7.8，仅增加交互与审查层。英文正文、中文翻译、图注、图表精读数据、参考文献和图表映射保持不变。

## 1. 布局过渡动画
- 右侧图栏：打开和关闭时同时执行栏宽、透明度和横向位移动画。
- 目录栏：折叠和恢复时增加透明度及位移动画。
- 批注本、阅读设置和图表精读：增加进入与退出过渡。
- 系统设置为“减少动态效果”时自动取消动画。

## 2. 分类搜索与准确定位
- 搜索结果按英文正文、中文翻译、中英文图注、图表内容和论文信息分类。
- 点击结果后定位到实际命中的文本节点，并短时标出匹配词和所在内容块。
- 不根据模型猜测章节或图号。

## 3. 图文布局预设
阅读设置底部新增“正文优先、图文均衡、图表优先”三个宽度预设。它们只修改目录和图栏宽度；用户拖动分隔线后自动退出预设。

## 4. 子图聚焦的安全实现
- 点击子图解读标题时，只聚焦对应的文字卡片。
- 本版本没有经过人工确认的子图坐标，因此不会在原图上生成或猜测任何定位框。
- 以后只有通过坐标、面板编号和截图三重检查的映射才能启用图像区域定位。

## 5. 严格审查机制
- 构建时检查正文和全部论文数据哈希。
- 运行时检查图卡、表卡、精读按钮、快速预览目标和正文引用目标。
- 未通过检查时自动停用分类搜索等新增功能，不影响原版阅读功能。
- 审查报告可在浏览器控制台读取 `window.__CANVAS_V080_REVIEW__`。
