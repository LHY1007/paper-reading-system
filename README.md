# Paper Reading System

面向学术论文的双语精读与图表精读阅读器。

## 版本规则

- 每次更新发布新的独立版本，不覆盖历史版本。
- 发布文件以版本号为前缀，其余名称使用下划线连接。
- 论文英文原文、中文逐段翻译、完整图注、图表映射和既有核心功能属于锁定内容。
- UI、交互与性能可以迭代，但不得借此删减、重排或改写锁定内容。
- 已删除的快速了解、证据审查、正文下方便捷注释等模式不得恢复。
