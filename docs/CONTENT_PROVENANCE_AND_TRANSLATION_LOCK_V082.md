# V0.8.2 内容来源与翻译锁

## 禁止混淆的两个任务

“把已有阅读器迁移到新功能框架”和“从原始 PDF 重新制作逐段双语阅读器”是两个独立任务。迁移只能继承来源文件已有的英文、中文、图像和解读，不能宣称完成了新的逐段翻译或内容校对。

## 新 PDF 的正式生成要求

正式生成必须直接读取 PDF 的段落、字体、坐标、图表区域和引用 span。英文正文按原段落保留；中文逐段严格翻译并保持术语一致；引用在翻译前通过版面特征标记并与双语块共享 reference ID；图注严格翻译与图表解读必须分离；任何摘要式中文都不能替代逐段翻译。

## 迁移批次要求

旧版来源文件迁移时，生成报告必须记录来源文件、继承段落数、图表数、精读数和来源附录状态，并明确标注“功能迁移”而非“重新翻译”。功能检查通过不自动代表翻译覆盖率或内容准确性已重新审查。

## 发布阻断

以下情况必须阻断发布：将核心段落摘要标记为全文逐段翻译；英文与中文块数量或顺序无法对应；图注被概括性解读覆盖；引用在 HTML 生成后通过无上下文数字正则批量猜测；旧来源缺失内容却未在报告中披露。
