# V0.8.2 CANVAS → Maas 逐区读者内容对照

本文件不比较 CSS 哈希或按钮数量，而是比较读者实际看到和使用的内容。当前 Maas HTML 被判定为废案；它只能作为失败样本，不得继续作为候选版或批量范本。

## 1. 论文标题区

CANVAS 原版同时显示完整英文标题、准确的中文学术标题、完整作者名单以及可展开的作者和单位信息。读者进入页面后能够立即确认论文主题、研究团队和出处。

当前 Maas 把英文标题原样放进中文标题位置，作者显示为 `Authors listed in the source PDF`，单位为空。代码不得再接受占位作者或英文复制标题。Maas 应显示中文标题“由肿瘤微环境决定的风险连续谱完善脑膜瘤分型，并揭示机器学习肿瘤分类的决定因素”，并从 PDF 后部作者信息页提取完整作者顺序、单位编号和通讯作者。

## 2. 期刊与论文信息

CANVAS 原版的信息卡面向读者，包含 Journal、Publisher、DOI、Article type、完整 Publication timeline、卷页信息、Journal scope 和领域定位。它们帮助读者理解论文级别、发表状态和学科位置。

当前 Maas 只显示 Nature Genetics、DOI、2026 和 `Source PDF, 32 pages`，同时把 SHA256 与 extraction diagnostics 暴露给读者。SHA、解析方式和质量审计只能写入构建报告，不能进入论文页面。Maas 的读者信息必须包括 Springer Nature、Received 30 October 2024、Accepted 10 December 2025、Published online 9 February 2026、Nature Genetics 58, 341–354 (2026)，并说明该研究位于脑膜瘤分子分型、肿瘤微环境和分类器解释的交叉方向。

## 3. 一页概览

CANVAS 原版的一页概览不是摘要复制，而是六个固定的阅读问题。每个回答都重新组织全文证据，使读者在进入正文前理解研究动机、队列、输入输出、主要发现、临床结果和限制。方法流程被压缩为一条有顺序的研究链，整体结论明确论文建立了什么以及尚未证明什么。

当前 Maas 把 DOI 和首页文字当研究问题，把“32 pages、199 blocks、16 assets、82 references”当核心数据，把 Ethics statement 当输入输出与方法流程，把首页句子重复放入生物学发现和临床结果，再用固定免责声明冒充局限。以上内容全部禁止渲染。

Maas 的概览必须明确：研究检验非肿瘤细胞是否改变 DNA 甲基化分类，并判断 NF2 突变型脑膜瘤更符合离散亚型还是连续风险谱；核心数据包括 26 例 snRNA-seq、120 例 IHC/MIBI、37 例空间 RNA-seq、4,502 例发现集甲基化数据、7,495 例参考甲基化数据、临床队列和 1,378 例 PU.1 TMA；分析输出是肿瘤与微环境信号分解、连续风险结构以及可临床量化的免疫细胞指标；生物学结果和临床结果必须分开陈述。

## 4. 正文目录与章节标题

CANVAS 原版的目录沿着科学论证展开。结果部分的标题直接说明每一阶段发现，例如空间拓扑、细胞邻域、CANVAS 生境预测和免疫治疗获益。方法部分保留原论文真实小节。读者可以从目录看懂论文逻辑。

当前 Maas 出现 `Front matter`、完整句子片段、多个 `References`、`Online content` 和标题碎片。这是 PDF 排版被误当论文结构。代码必须建立章节白名单与上下文判断，清除页眉、作者行、日期、图注、标题碎片和重复参考文献标题。结果目录应围绕以下论证展开：脑膜瘤微环境组成；不同分级和甲基化类别中的 TAM 状态；肿瘤与基质信号如何共同影响分类器；NF2 突变型连续谱；亚克隆贡献；免疫细胞与复发；PU.1 临床验证。

## 5. 双语正文

CANVAS 原版以一个真实来源段落对应一个双语块，英文保持原文，中文根据上下文统一术语，正文引用和图表引用仍可交互。段落边界由原论文语义决定，而不是固定字数或 PDF 文本框数量。

当前 Maas 的中文栏大量复制英文，首页、页眉、轴标签和图注混入正文，一些真实段落被拆碎，另一些不相关内容被合并。解析器只能提供来源段落候选和页码；段落合并、章节归属与中文翻译必须经过内容阶段。未翻译正文、句中截断、页眉泄漏和图注混入正文均应直接阻止渲染。

## 6. 图卡标题与简介

CANVAS 原版的图卡标题包含图号和完整描述性标题，中文标题完整翻译；简介用一至两句话说明该图在全文中回答什么问题。读者即使未展开图片，也能判断是否需要阅读。

当前 Maas 把主图统一显示为 `Fig.`，扩展图统一显示为 `Extended Data Fig.`。这丢失了图的科学主题。Maas 主图必须分别显示完整标题，例如 Figure 1 是脑膜瘤分子分类体系与 snRNA 队列概览，Figure 4 是 NF2 突变型脑膜瘤更符合连续谱而非离散亚型，Figure 6 是 PU.1 免疫组化量化 TAM 对风险预测的改善。

## 7. 图像与图注

CANVAS 原版保留完整、高分辨率来源图，英文图注为完整原文，中文图注为完整翻译，图注与正文不混合。补充图也按独立资产管理。

当前 Maas 的自动裁图虽然找到了主图和扩展图，但部分图注吸收了正文、轴标签或下一段内容；中文图注直接复制英文。代码必须先确定图像区域和完整 caption 边界，再进行翻译。任何 caption 与相邻正文重叠、图像缺面板、图注未翻译或标题只剩图号的资产都不能进入阅读器。

## 8. 图表精读

CANVAS 原版的图表精读不是复述图注。每张图包含整图阅读顺序、与前后图的关系、逐子图或逻辑块解释、坐标轴和比较对象、关键结果、图级结论以及证据边界。它承担“帮助读者读懂实验”的核心功能。

当前 Maas 把英文 caption 复制到 overview、panel explanation 和 conclusion，或使用固定免责声明。这样的内容没有任何阅读辅助价值。每个 panel 的解释必须回答：输入或对象是什么；横纵轴或颜色代表什么；比较了哪些组；结果方向和统计证据是什么；该结果如何支持整图结论；不能从图中推出什么。未完成逐子图解释的图卡不得显示“图表精读”完成状态。

## 9. 表格

CANVAS 原版的补充表以结构化 HTML 表卡呈现，可滚动、检索和在右侧查看。列名、行内容和中文解释保留表格逻辑。

当前解析器把所有表格都当作 figure image，因此 Maas 没有任何标准表卡。代码必须先识别 Table/Extended Data Table，再优先生成 headers 与 rows。只有跨页复杂合并单元格无法可靠重建时，才允许保留图片回退，并在审计中明确说明，不能静默伪装成图。

## 10. 术语

CANVAS 原版的术语解释围绕论文中反复出现且影响理解的概念，并在上下文中说明含义。缩写只高亮必要部分。

当前 Maas 没有根据论文建立术语体系。至少需要覆盖 NF2-wild-type/NF2-mutant、methylation class、UCSF group、TAM、microglia-like、myeloid-derived macrophage、NMF、NNLS、classifier probe、calibrated score、PU.1、C-index 等，并解释这些词在本研究中的具体用途。

## 11. 参考文献

CANVAS 原版保留原编号和完整参考文献，正文编号可以打开对应条目。连续引用范围会显示全部论文。

当前 Maas 只提取 82/86 条，并将已提取条目重新顺序编号，从表面上隐藏缺失位置。代码必须保存源编号，报告缺少哪几条，并在参考文献未完整前阻止最终渲染。

## 12. 生成流程

正确流程是：PDF 解析器生成英文证据、页码、图像、原始图注和参考文献候选；任务构造器按照 CANVAS 蓝图为每个模块给出具体生成要求与证据范围；内容阶段完成论文级综合、章节清理、全文翻译、图表精读、表格结构和术语；读者内容门禁逐项检查；全部通过后，固定壳层渲染 HTML。

错误流程是：解析器直接用首句、末句、页数和 Methods 片段填满 schema，然后翻译并渲染。该流程已被废止。
